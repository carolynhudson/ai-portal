Vulkan SDK: AMD's RADV driver is the open-source Vulkan implementation for AMD GPU. For building llama.cpp, use the Lunarg Vulkan SDK (downloaded to ~/ai/sdk/vulkan/ or ~/vulkan/). The runtime Vulkan drivers come from Ubuntu's vulkan-radeon / radv packages or ROCm's integrated RADV — you do not need an AMD-specific Vulkan SDK for runtime. The build SDK and runtime driver are separate: build SDK provides vulkan.h and vkcreateinfo.h for CMake; runtime uses the system RADV driver.
