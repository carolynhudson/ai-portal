Settings a personality can set

The keys the portal has a definition for, and therefore the keys a settings editor can offer. Each row is the same definition the generator validates against, so what the page explains and what the file is checked against cannot drift apart. Keys the router controls (host, port, alias, model, hf-repo) are absent: it removes or overwrites them at launch, so setting one would look like a setting and do nothing.
