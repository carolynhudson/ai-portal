Settings editor

What a personality may set, its type, its default, and where each key comes from is the settings reference on Help — the same registry rows this form is built from, one section per key, linked from every row below. The reference moved there (§6.14.1q / queue 33): it is reference material, and it sat in the middle of the working page.

Propose changes, preview the exact file and the exact cost, then apply. Nothing is written and nothing is snapshotted until Apply, and Apply restarts {{ router_unit }} so the router actually re-reads the file. The fields start on the values this personality already carries, so what you are editing is the configuration, not an empty form -- and a field you leave alone is sent unchanged, which is the same as not touching it.
