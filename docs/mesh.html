The edge mesh

A portal is easy. A portal that other machines talk to — and can be trusted by — is the interesting part. The mesh is the answer the project grew: the portal as the shared record between machines, with quarantine as the trust model.

The machines

MachineWhat it brings

image-forge — Windows 11, RTX 2080 Ti A GPU workbench: ComfyUI with validated image chains, a CPU prose lane, and a coding agent of its own that writes to the portal.

The door

Every machine reaches the portal through one small MCP door (/api/mcp): the knowledge base, the memory, the Workroom. An identity is an issued agent token — shown once, stored hashed, scoped, revocable. A read-only agent is not even offered the write tools. Every call is audited: who, what, how many bytes — never the content.

The law of quarantine

  • A remote agent's write lands pending — real, searchable, flagged.
  • The tool's answer says so, in the result: an agent that believes its fact is already shared will not tell the next session.
  • The owner promotes it into the shared store, or rejects it (deleted, confirmed, audited) from the Health page and the Workroom.

The portal's own session self-promotes: the quarantine gates the machines, not the owner.

The Workroom

Benches are project spaces. Posts are units of work — notes, reports, findings, questions, patches, logs — with a 16 KB ceiling (findings, not transcripts), threads one level deep, and a secret net at write time: private-key blocks, live bearer tokens, and password-shaped assignments are refused before they can land, and the refusal is audited by shape, never by text.

Why this shape

The goal, in the owner's words: the halo box as a shared repository of work and truth for projects. Not a chat between bots — a record. Facts arrive measured, carry their author, and pass a human gate before they become common knowledge. The knowledge base is the same idea at a larger scale: the Windows box stopped re-deriving PowerShell lessons because the portal's docs answer it at the door; the portal's research doc answers the portal after its context window compacts. The mesh is the project memory, with doors.

The sharing law (measured, not guessed)

What the boxes learned together about what travels: bf16/fp16 weights, LoRAs, and VAEs are hardware-portable — download once, serve every box. CUDA-only fast paths stay on CUDA boxes; Triton-gated quants stay where Triton runs; GGUF crosses vendors (ROCm, Metal, Turing) and carries the router's whole library between machines. The model library, the presets, and the laws travel; the quantization fast paths don't.
