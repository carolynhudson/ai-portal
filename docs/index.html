One desktop machine.
All the AI. No cloud.

A web console that manages, updates, and connects the AI tools on a single AMD Strix Halo box: the llama.cpp router, ComfyUI, model files, projects, coding agents, and the machines next door.

This project began as a personal challenge: can a fully functional Edge AI tools management portal be built using only edge AI tools — models running on the family's Framework Desktop (AMD Ryzen AI Max+ 395, 128 GB shared memory)? The answer, so far, is yes. The portal was planned, written, tested, and reviewed by coding agents running on the machine it manages — and the portal in turn launches those agents. Nothing here rents intelligence.

What it does

Models, decoded

The portal reads GGUF files themselves — quant, architecture, trained context — and turns them into router personalities, honest memory budgets, and safe migrations. Nothing moves before it is verified.

Downloads with a receipt

One field, org/model:QUANT: the byte plan comes first, every file is verified at the door, and the model is filed where the router will find it. The witness: 21.4 GB planned, landed byte-exact.

Health with the coupling visible

The GPU aperture, ROCm ↔ llama.cpp ↔ torch coupling, pending updates, disk. The portal reports system updates; it never applies them.

Projects and a reachable harness

A folder, a personality, a launch: a real coding session starts and stays reachable — from the browser, from the network, after restarts.

A mesh, not a script

The Windows box next door reads the portal's knowledge base through a scoped MCP door, posts measured results to a shared Workroom bench, and its writes land quarantined until the owner promotes.

Trust, tested

1,366 tests. Destructive actions confirm; deletions verify first; the suite drives every page in a real DOM and fails dead controls.

The story in three lines

The 4096-token mystery. An 88 GB model loaded cleanly and reported a 4096-token context — a “broken model” that was really a 64 GiB driver cap on the GPU's window onto memory. The fix raised the window to 108 GiB, and the portal now watches it, because that bug comes back by itself.

The machines collaborate. The first Workroom exchange: a measured A/B of four image-model chains posted by a Windows box, answered in-thread, promoted by the owner — the record stays with the project.

It remembers. Every design doc, journal entry, and lesson is searchable by the agents through a door the portal built for them — on this box and across the mesh.
